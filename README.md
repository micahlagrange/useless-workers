# useless-workers

Morphi: creatures with hunger that pull tasks off a job queue. LÖVE2D, Feb 2024.

The next game builds on this one. See [docs/human-resources-design-doc.md](docs/human-resources-design-doc.md) for the design doc: an indirect-control colony sim that reuses the worker and job queue code here, the noise world from top-down-minecraft, and the abilities, UI, and scoring from control-the-environment.

Run with `love .` or `./serve.sh` for the browser build.
